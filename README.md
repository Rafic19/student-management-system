
# Student Management System

A web-based Student Management System built using Python, Flask, and MySQL.

## Features
- Add student records
- View student records
- Edit student details
- Delete student records
- Search student records

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Setup
1. Install Python and MySQL.
2. Install dependencies using `python -m pip install -r requirements.txt`.
3. Configure your local `.env` file with your database credentials.
4. Create the required database and tables in MySQL.
5. Run the application using `python app.py`.
6. Open `http://127.0.0.1:5000/` in your browser.

## Security
Never upload your `.env` file or database passwords to GitHub.
